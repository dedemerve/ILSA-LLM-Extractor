We evaluate a tiered machine learning framework that

of non-cognitive factors and identify the top three factors
suitable for ML training. The third component consists of a

conclusions.

Abstract—There is a signiﬁcant interest in the education
community to use machine learning (ML) techniques to model
students’ achievement as a function of non-cognitive factors. In
this research, we present a tiered machine learning framework
designed for educators to apply ML and classify student achievement. The framework comprises three components including
SMOTE balancer, a council of selectors, and a suite of learners.
The SMOTE balancer removes any data imbalances, thereby
reducing ML bias. The council of selectors collectively votes to
elect the top three features for effective model training. The
suite of classiﬁers comprises popular ML models that train
using the selected features. The suite of classiﬁers also includes
a combiner, which uses ML performance metrics and users’
analysis preferences to select an effective model for classiﬁcation.
Using the Trends in International Mathematics and Science
study (TIMSS) data on Singapore students, we evaluate the
framework and achieve up-to-par prediction results, despite the
low correlation between the dependent variable and features.
Our goal is to offer educators an easy-to-use ML framework
that assists with the analysis of large education data.
Index Terms—machine learning, classiﬁcation, information
mining, education data analysis, education, multi-agent systems

Figure 1 shows the multi-tiered framework comprising three
components: the SMOTE class balancer, feature selection
council, and a suite of classiﬁers. The framework inputs the
labeled training data set and recommends a classiﬁcation
model that is most amenable to a user’s analysis preference.
In what follows, we explain the three components of the
framework.
The framework’s ﬁrst component, Synthetic Class Oversampling Technique (SMOTE) [2], alleviates class imbalance
in the training data set. Speciﬁcally, it generates a synthetic
minority class by identifying the K-nearest neighbors for each
minority class instance. SMOTE creates synthetic instances
along the line connecting an instance to one of its neighbors,
thereby introducing diversity to the minority class.
The framework’s second component, the feature selection
council, comprises seven feature selection methods to identify
the top features for class prediction. The methods include
information gain, random forests, recursive feature selection,
permutation, forward feature selection, backward feature selection, and regularization. The council operates on a simple
majority, meaning that the framework uses the most commonly
identiﬁed features to build the classiﬁcation models. To promote model simplicity and avoid overﬁtting, the framework
selects the top three most-voted features. More information
on the feature selection methods can be found in [3].
The third component of the framework, the suite of classiﬁers, comprises ﬁve machine learning classiﬁers including
XGBoost, decision trees, logistic regression, support vector
machine (SVM), and the Naı̈ve Bayes classiﬁer. To train these
ML models, the framework partitions the training data into
two parts: training and evaluation. The framework employs the
training partition data to train the models using scikit-learn 3 .
Component 3 employs a combiner to identify an effective
classiﬁcation model that best suits a user’s analysis preference.
The combiner employs model performance metrics including accuracy, precision, recall, and F1-score along with the
user’s analysis preference to identify an effective classiﬁcation model. Component 3 generates the performance metrics
using the evaluation partition data. The combiner employs the
ﬂowchart given in Figure 2 to determine an effective model. As
shown in the ﬁgure, if a model’s accuracy is below a threshold,
then it is discarded. Otherwise, the framework checks with the
user if either false positive or false negative is more costly
for their analysis. If false positives are more costly, then the
combiner selects a model with the highest precision. If false
negatives are more costly, then the combiner selects a model
with the highest recall. If both the false positives and negatives
are equally important, then the combiner selects a model with
the highest F1-score.

A. Education Data
We execute the framework using the Trends in International
Mathematics and Science Study (TIMSS) assessment data on
Singapore school students. TIMSS measures science achievement, a continuous dependent variable, as a function of ﬁve
continuous independent variables including parents’ socioeconomic status, students’ computer self-efﬁcacy, instructional
clarity of science lessons, students’ conﬁdence in science, and
how much the students value science. We assign the science
achievement scores to one of the ﬁve classes as follows. We
assign scores ≥ 90th percentile to the ‘excellent’ category
(E), scores between 80th -90th percentile are classiﬁed as ‘very
good’ (AA), scores between 70th -80th percentile are classiﬁed
as ‘average’ (A), scores between 60th -70th percentile are classiﬁed as ‘below average’ (BA), and scores ≤ 60th percentile
are assigned to the unsatisfactory category (U ). Using the ﬁve
independent variables, we employ the framework and its three
components to predict the science achievement (dependent
variable) class.
Figure 3 shows the correlation between the science achievement scores and the ﬁve independent variables. According to
the ﬁgure, the independent variables that have the strongest
correlation with science achievement are socio-economic status (0.44), conﬁdence in science (0.32), and valuing science
(0.29). It is worth noting that this real data set observes a moderate correlation between the dependent and the independent
variables. Therefore, we expect the machine learning models
to achieve moderate accuracy. However, choosing the right
machine learning model based on user preference is crucial
for an effective analysis. The framework accomplishes this
task using the combiner feature discussed ahead.

over time reveal a generally positive relationship between
SES and academic performance [4][5]. Students from lowSES families tend to perform worse academically than students

before children start school, and it persists throughout their
educational careers [6].

focus on the improvement of educational processes both at
home and in school for students from low-SES families [8].

in their children’s education [9][10]. They are more likely to

V. C ONCLUSIONS
This paper presents an evaluation of a tiered machine
learning framework to categorize science achievement among
Singapore students using important non-cognitive factors. The
framework employs a tiered approach comprising three components. The ﬁrst component removes any data imbalance
to avoid bias in machine learning. The second component
employs a council of feature selectors to identify the top three
non-cognitive factors that best predict the science achievement
class. The third and ﬁnal component includes a suite of
machine learning classiﬁers and a combiner, which uses model
performance metrics and user’s analysis preference to select a
machine learning classiﬁer for prediction.
Using real-world data, the framework identiﬁes the top three
factors that best predict the science achievement. These include
the socioeconomic status of parents, conﬁdence in science, and
how much students value science. Although the data contains
artifacts such as moderate correlation, the framework achieves
accuracy over 50% and a mean absolute error (MAE) in
prediction as low as 0.99. This low MAE implies that even
if the model mis-predicts the science achievement class, it
does so by no more than ±0.99 categories. This research also
demonstrates a plausible machine-learning strategy for data
analysis scenarios that observe a low correlation between the
dependent variable and predictors.

Computer self-efﬁcacy — Much empirical research has
demonstrated the positive and often powerful effect of computer self-efﬁcacy on achievement [11][12]. Students with
high computer self-efﬁcacy are more likely to use computers
and solve problems effectively with speciﬁc computer skills.
Students with high levels of self-efﬁcacy participate actively
in class, work harder, persist longer, adopt learning strategies,
and have less adverse emotional reactions when encountering difﬁculties. Given the similar cognitive and technical
levels, students tend to spend more time using computerrelated skills and therefore more engaged in their learning
processes [13][14]. Students are thus less likely to experience
anxiety or frustration when using computers. As technologies
are incorporated into education, computer self-efﬁcacy has
been regarded as a useful tool supporting the learning process.
Instructional clarity — Instructional clarity provides students with an explicit understanding of the learning goals,
provide clear instruction on how to achieve those goals, and
provide opportunities for students to practice and apply what
they have learned [15]. When the teacher’s instruction is clear,
students are more likely to be engaged in the learning process
and have a positive attitude toward the subject. In the study that
took place in Hong Kong, [16] also reported that instructional
clarity improved students’ enjoyment of learning and reduced
boredom in the classrooms.
Conﬁdence in science — Results across studies revealed
that students’ conﬁdence in science is signiﬁcantly and positively associated with science performance [17]. Conﬁdence is
therefore a key factor for academic success, as it can lead to
increased motivation, effort, and persistence. Conﬁdence as a
non-cognitive factor and its association with achievement has
been studied by different scholars ( [18],[1],[19]) and found
to be an important predictor of science achievement.

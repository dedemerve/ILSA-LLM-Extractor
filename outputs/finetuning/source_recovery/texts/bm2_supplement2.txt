Overview
This supplement contains documentation of national adaptations to the international versions of the
background questionnaire items.  The accompanying TIMSS 1999 User Guide contains a description of
the TIMSS 1999 background questionnaires.
This documentation provides users with a guide to evaluate the availability of internationally comparable
data for use in secondary analyses involving the TIMSS 1999 background variables. The documentation
of national adaptations is presented in four separate sections corresponding to each questionnaire type:
• 
Section 1:
Student Background Questionnaire
• 
Section 2:
Mathematics Teacher Background Questionnaire
• 
Section 3:
Science Teacher Background Questionnaire
• 
Section 4:
School Background Questionnaire
Each section contains general item information as well as specific national documentation about
individual background questions in order of questionnaire item location. In general, information is
included when the version of the question administered was different from the international version of
the question as it appears in the international version of the questionnaires. All variables are listed in this
documentation regardless of whether there were national adaptations made to the question or not. For
each question, when applicable, the following information is provided:
• 
Questionnaire Item Location Reference
• 
Question (an abbreviated version of the main question with any relevant sub-items and general
notes)
• 
Variable Names(s)
• 
Link to 1995:  If applicable, the analogous questionnaire item location reference and variable
name(s)

The version of the question shown in the documentation in this supplement is a shortened version
included to communicate the basic information about what was asked in each question. Its purpose is
also to aid in the interpretation of the specific documentation comments. For the exact question as it
appears in the International version of the questionnaire please see Supplement 1 of this User Guide.
The National Adaptation Documentation for each question lists any countries for which internationally
comparable data for the indicated variable are either unavailable or for which data are included with
notes on differences between the national and international versions of the questions.  It should be
noted that these adaptations pertain to the 1999 data.  Refer to the 1995 Supplement 3 for information
related to 1995 data.  It should also be noted that this documentation does not include any cases where
simple recodes of the national data were made to produce data that is comparable internationally in the
international variables (e.g., option reversals).
In the National Adaptation Documentation, countries are given one of two different data codes with the
following definitions:
• 
Code D: National data for country are included in the international database.
This code is used for questions that were to be defined by the country and the specific national
version is considered appropriate for comparison.1 To assist the user in data interpretation of
these questions, some brief documentation is included to describe the national version of the
questions. Some documentation of changes between 1995 and 1999 are also included.
• 
Code X: National data for country are NOT included in the international database.
This code is used to refer to all questions that were not administered, not applicable, or deleted
for any of several reasons (e.g. not internationally comparable, removed per country request, or
removed due to other data problems). A general comment is included for the majority of these
cases: ‘Question not administered or data not available’. Other comments may be included for
some variables where some description is required to explain the absence of data.
The documentation provided is as complete as possible given the information provided by the National
Research Coordinators (NRC) at the time this document was published. The review of national

General Documentation Issues for Questionnaire Items
General Science and Separate Science Versions of the Student Questionnaires
Two versions of the student questionnaire were administered in TIMSS 1999: a general science version
(identified as SQ2) and a separate science version (identified as SQ2S).  Countries administered the
version of the questionnaire that was most appropriate based on the way science was taught to their 8th
graders. The general science version was used in countries where science is taught in integrated science
classes. The separate science version was used in countries where the sciences are each taught as separate
subjects (biology, earth science, chemistry, and physics).  Students in each country have valid data only
for those variables associated with the version of the questionnaire administered in their country.
In a few cases, countries used a modified version of the student questionnaire omitting some of the
science subject areas, combining subject areas, or combining questions from both the separate science
and general science versions. As a result, these countries were handled somewhat differently in the
international database and report tables or figures. All of these special cases are listed below.
Special Cases for the Student Questionnaires
Belgium (Flemish): Administered the separate science questionnaire, but excluded the chemistry
questions.
Chinese Taipei: Students enrolled in grade 8 take physics/chemistry.  Biology is taught in grade
7and Earth science in grade 9.  They administered the general science version of questionnaire.
Questions pertain to "natural science".
Indonesia: Administered the general science questionnaire; however, the data pertain to ‘IPA’ courses,
which are composite courses taught by biology and physics teachers.
Latvia:  Administered the separate science questionnaire, but excluded the Earth science questions.
Lithuania: Administered the separate science questionnaire, but excluded the Earth science questions.
Netherlands: Administered the separate science questionnaire; however, the physics data pertain to
combined physics/chemistry courses; no separate data are included for chemistry.
Slovenia: Administered the separate science questionnaire, but excluded the Earth science questions.
